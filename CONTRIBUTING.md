# Contributing to ClaimWatch NZ

This project is being built in the open, ahead of the 2026 NZ general election, and is designed to be scrutinised. Disagreement is a contribution.

## How to contribute

### Contest a design decision
Every significant decision is an [ADR](adr/). If you disagree with one:
- **Open an issue** referencing the ADR number, or
- **Open a competing ADR** (`adr/NNNN-...` with the next number) describing your alternative — competing ADRs are explicitly welcomed and will be discussed in issues.

### Contribute to docs
PRs against `docs/` are reviewed by the maintainers. Factual claims in documents should cite sources.

### Contribute code (from October 2026)
Code lands after the design phase. Standards will be defined in the first code PRs; prompts and schemas will be versioned so harness runs stay reproducible.

### Label ground truth or contest verdicts
See `docs/EVALUATION.md` — labelling help and contest participation are the highest-value non-code contributions during the election cycle.

## Principles for contributions

1. **Claims, not persons.** Contributions (like all project output) must address claims, not individuals' character. Content about individuals that breaches HDCA communication principles will be removed under the content-host process.
2. **Party-blind methodology.** Anything that sets different standards for different parties will be rejected. If you believe a rubric or grid is biased, the fix is a change to the published criterion — not per-claim exceptions.
3. **Evidence first.** Design arguments and label disputes must cite primary sources.

## Governance

- **Maintainer:** Bradley (@bradleyscott) during the 2026 build; the steward-panel structure is described in ADR-0005 and will be stood up post-election.
- **Decision process:** significant decisions as ADRs, discussed in issues, decided by maintainers, recorded in the ADR status line.
- **Transparency:** the verdict audit log, evaluation harness results, and funding disclosures are public. See `docs/LEGAL-COMPLIANCE.md` for the promoter statement.

## Conduct

Standard open-source conduct: critique work, not people; no partisan campaigning in project spaces; election-period moderation follows the HDCA process in the legal doc.
