How an open-web check works — and what it did here

9 Sept · 9:20–9:41 ammode: open-webneeds persistence

With no official series, the claim is turned into questions evidence could answer and searched for those, not for the claim. A run is capped at a set number of rounds; whether the cap was reached is recorded, because a capped run has not finished looking.

Questions asked of the record
1. Does any agency publish a gang-membership count? → partly — Police publish a count with a definition that excludes associates.
2. What was that count in 2017 and now? → no — the series does not go back that far.
3. Has any other body estimated the change? → only commentary, no method published.
Searches run
7 searches over 2 rounds — the cap was not reached, so the search stopped because it had run out of new questions, not because it ran out of budget.
Why the run ended here
The loop stops when an assessment judges the evidence sufficient, or when the cap binds. Here it judged the evidence insufficient and the questions exhausted — the honest reason a verdict says “not enough evidence” rather than guessing.

What an open-web check cannot tell you: it can only report what is published. Nothing here can establish a figure that no one has counted — so an absence of evidence is reported as exactly that, and never as evidence the claim is false.

Where this check stops

9 Sept · 10:02 amstored

A verdict that says “not enough evidence” has to say what is missing and what would settle it, or it is just a shrug.

What this check could not settle
  • The 2017 baseline. No published count reaches back that far.
  • Who counts as a member. Police count list members; the claim's “membership” is undefined, and associates are excluded.
  • Whether the rise is real or a change in counting. The Police list's scope has changed since 2017 and no note explains how.
What would change this verdict
  • A published series with a 2017 baseline and a stated definition — the number would then be checkable and this page would be superseded.
  • A Police note explaining the list's scope changes — that would turn “unknown change” into an arithmetic question.
  • The claim's own definition of membership, if one was given elsewhere.
