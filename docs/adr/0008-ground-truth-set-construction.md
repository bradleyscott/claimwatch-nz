# ADR-0008: Ground-truth set — sampled from historical Hansard, labelled in public, scored blind

*Status: Proposed · Date: 2026-09-07 · Deciders: Bradley, Dave*

## Context

ADR-0001 makes the evaluation harness load-bearing. The ground-truth set needs a construction method that is cheap (no payroll), defensible against bias claims, and free of temporal leakage.

## Decision

- **Source**: claims sampled from historical Hansard (initially 2024–2025 — pre-current-cycle), via the production detection pipeline; complemented with a smaller set of news-derived claims.
- **Labelling**: operator + one other for the 2026 cycle (target n=100, double-label 20%); journalism-school partnership is the scale-up path.
- **Label schema**: claim text, speaker, party, date, source, verdict (true / false / partially true / misleading-selective / unverifiable), cited primary sources, reasoning, evidence-availability note, labeller ID, label date.
- **Publication**: CC BY 4.0, versioned, with label revisions only through the same contest-and-mutation process as verdicts.
- **Scoring**: blind (pipeline never sees labels), accuracy by claim type and confidence band, calibration reported, 10–20% held out and never tuned against.
- **Regression gate**: every pipeline change re-runs the harness (see `docs/EVALUATION.md`).

## Alternatives considered

- **Use AVeriTeC's public dataset directly.** Rejected as primary (US/open-web distribution, not NZ political claims) but kept as a secondary sanity benchmark for the verification loop.
- **Synthetic/LLM-labelled ground truth.** Rejected: circular (labels generated by the same class of system being measured); LLM labels may assist *triage* of what to label, never the labels themselves.
- **Larger n later / perfect after launch.** Rejected: an unpublished harness protects nobody; 100 published claims before launch beats 1,000 after.

## Consequences

- n=100 gives a wide confidence interval; published with the interval, per `docs/EVALUATION.md` §6.
- The set is an asset beyond the project: a labelled NZ political-claims corpus that does not currently exist.
